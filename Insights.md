## Step nr

### What was new to me
- Separating the website into HTML for content, CSS for design, and JavaScript for behavior.
- Creating forms for a dog profile, daily exercise, and dated weight measurements.
- Showing exercise as bars and weight as a line in one 30-day chart.

### New things I did learn
- A label's `for` value connects it to an input's `id`.
- CSS Grid and media queries help make forms readable on different screen sizes.
- JavaScript event listeners handle form submissions, and `localStorage` keeps data after reloading the page.
- Loops can create one chart bar for each day, while SVG can draw the weight line.
- Exercise minutes and weight need separate scales because they use different units.
- Browser testing helps check that saving and loading data work as expected.
